# Host the API on Cloud Run and PostgreSQL on Neon Free

Host the NestJS API on Google Cloud Run and PostgreSQL on Neon's Free plan. Use request-based Cloud Run billing with zero minimum instances to target low costs while gaining experience with managed container deployment, accepting cold starts and the configuration needed to connect services across providers. Neon is constrained to its free-plan allowances; Cloud Run and supporting Google Cloud services remain usage-based, so the combined deployment is not guaranteed to cost $0.
