# Use NestJS with Apollo Server

Use NestJS with Apollo Server through Nest's official Apollo driver, retaining Nest's default Express HTTP adapter. Choose Nest's modules, dependency injection, and application conventions over assembling the application directly with Express to gain experience with an opinionated TypeScript backend framework, accepting the additional framework concepts and wiring. Use Apollo rather than Yoga for its official Nest integration, while retaining the schema-first API and keeping business rules and tour-access checks in application services outside the resolvers.
