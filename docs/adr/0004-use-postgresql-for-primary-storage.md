# Use PostgreSQL for primary storage

Use PostgreSQL as the backend's primary database. The relationships among organizations, tours, users, tour access, and itinerary items fit relational storage, and the project is an opportunity to gain practical experience with SQL, relational constraints, and schema migrations after using Firestore on other hobby projects. Choose PostgreSQL over Firestore and MongoDB while keeping hosting a separate decision: this is a non-revenue hobby project, so deployment must remain inexpensive, with no provider or monthly budget yet agreed.
